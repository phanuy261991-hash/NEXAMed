# NEXA UI Design Guideline

Version: 1.0


## Design Philosophy

NEXA is an enterprise management application.

Design characteristics:

- Professional
- Clean
- Calm
- Efficient
- Data-focused


Avoid:

❌ Gaming style
❌ Neon colors
❌ Excessive gradients
❌ Glassmorphism
❌ Large shadows
❌ Decorative animations


The interface should feel like:

- ERP software
- Hospital management system
- Business dashboard

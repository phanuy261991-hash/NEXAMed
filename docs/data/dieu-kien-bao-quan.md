# MASTER DATA DƯỢC PHẨM: ĐIỀU KIỆN BẢO QUẢN (STORAGE CONDITIONS)

Danh mục **Điều kiện bảo quản** được chuẩn hóa phục vụ quản lý kho dược (GSP/GDP), kê đơn, cảnh báo quá nhiệt trên phần mềm và xuất file XML BHYT (Quyết định 130/QĐ-BYT).

---

## I. BẢNG DANH SÁCH MASTER DATA

| Mã UI (`code`) | Mã Bộ Y tế (`byt_code`) | Tên ngắn UI (`short_name`) | Tên đầy đủ chuẩn (`name`) | Mô tả chi tiết |
| :--- | :--- | :--- | :--- | :--- |
| **S01** | `1` | Thường (Thoáng mát) | Điều kiện thường (Thoáng mát) | Nơi khô ráo, nhiệt độ 15°C - 30°C, độ ẩm ≤ 75%, tránh ánh nắng trực tiếp |
| **S02** | `2` | Mát (15°C - 25°C) | Nơi mát | Nhiệt độ từ 15°C - 25°C |
| **S03** | `3` | Lạnh (2°C - 8°C) | Kho lạnh / Tủ lạnh | Nhiệt độ từ 2°C - 8°C (Vắc xin, sinh phẩm, Insulin) |
| **S04** | `4` | Đông lạnh (≤ -15°C) | Kho đông lạnh | Nhiệt độ ≤ -15°C |
| **S05** | `5` | Tránh ánh sáng | Tránh ánh sáng trực tiếp | Bảo quản trong bao bì kín, Tránh ánh sáng chiếu trực tiếp |
| **S06** | `6` | Tránh ẩm (Độ ẩm ≤ 60%) | Nơi khô ráo (Khống chế độ ẩm) | Bảo quản nơi khô ráo, độ ẩm tương đối ≤ 60% |
| **S07** | `7` | Kiểm soát đặc biệt | Hướng thần / Nghiện / Tiền chất | Kho/Tủ riêng có khóa chắc chắn theo quy định Dược chính |
| **S99** | `9` | Khác | Điều kiện bảo quản khác | Theo chỉ dẫn cụ thể trên nhãn nhà sản xuất |

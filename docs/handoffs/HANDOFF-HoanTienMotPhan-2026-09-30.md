## 2. Thiết kế (tóm tắt)
- **Dữ liệu**: bảng `invoice_refund` (mỗi lần hoàn: `refund_no` mã `PHT…`, `reason`, `refunded_at`, `total_amount>0`) + `invoice_refund_line` (`invoice_line_id`, `quantity>0`, `amount>=0`, `restocked`, `stock_receipt_id`; CHECK restocked ⇔ có receipt) + `payment.refund_id` (gom dòng REFUND theo lần hoàn). KHÔNG thêm cột vào `invoice` — "đã hoàn" luôn = SUM payment REFUND.
- **Tính tiền** (`packages/core/src/billing/partial-refund.ts`, ĐÃ XONG + test): `allocateInvoiceDueToLines` (chia `dueAmount` xuống dòng, largest-remainder, tổng khớp từng đồng; PER_LINE dùng net từng dòng) → `computeLineRefundAmount(net, qty, đãHoàn, hoànLần này)` (cộng dồn `round(net·k/Q)` bằng BigInt → hoàn hết đúng bằng net) → `allocateRefundAcrossPayments` (WALLET trước).
- **Flow `InvoiceRefundService.refundItems`** (1 transaction): đọc hoá đơn `findByIdWithLines(dto.invoiceId)` (phải thuộc `:encounterId`, else 404) → chỉ `PAID` (CANCELLED/REFUNDED → `InvoiceClosedError`, UNPAID → `InvoiceNotRefundableError`) → mỗi dòng: phải là dòng thuốc (`InvoiceLineNotRefundableError` 422), `quantity ≤ quantity − đãHoàn` (`InvoiceRefundQuantityExceededError` 422) → tổng tiền (=0 → `InvoiceRefundZeroAmountError`) → còn-hoàn-được theo phương thức = Σ PAYMENT − Σ REFUND (dùng `PaymentSides.refundRows`) → `allocateRefundAcrossPayments` (shortfall>0 → 422) → khoá phiên bản: nếu `đãHoàn + tổng == dueAmount` thì `markRefunded(dto.version)` (→ REFUNDED) NGƯỢC LẠI `touchForPartialRefund(dto.version)` (0 dòng → `ConcurrentModificationError`) → sinh `refundNo` qua `BusinessCodeService.generate(tx,…,'INVOICE_REFUND',now)` → `InvoiceRefundRepository.create` → nếu có dòng `restock`: `StockReceiptService.createReturnFromUseReceipts(tx,…,{occurredAt, refundNo, lines:[{stockIssueLineId, quantity}]})` (trả map stockIssueLineId→receiptId) → `createLine` từng dòng → `PaymentRepository.createRefund(…, refundId)` từng phần bổ (cashAccountId qua `InvoiceService.resolveCashAccountId`, cashierShiftId/drawer đọc TRƯỚC transaction như `refund()`), dòng `WALLET` → `walletService.creditBack(tx,tenantId,actorId,patientId,amount,invoice.id,note,meta)` → audit `invoice.partial_refunded` (`afterJson`: refundNo, amount, lines, reason, fullyRefunded) → trả `toInvoiceResponse(đọc lại)`.
- **Endpoint**: `POST /billing/invoices/:encounterId/refund-items`, body = `refundInvoiceItemsRequestSchema` (đã có trong `packages/shared/src/billing.ts`), `@RequirePermission('invoice','refund_drug',{entityIdParam:'encounterId'})`, `@HttpCode(200)`.
- **Module**: `BillingModule` thêm `forwardRef(() => InventoryModule)` (Inventory đã `forwardRef(BillingModule)`, đã export `StockReceiptService`); `InvoiceRefundService` inject `@Inject(forwardRef(() => StockReceiptService))`. **Bắt buộc kiểm bằng boot thật `node apps/api/dist/main.js`** (không chỉ typecheck) — vòng phụ thuộc này từng gây lỗi require() thật.

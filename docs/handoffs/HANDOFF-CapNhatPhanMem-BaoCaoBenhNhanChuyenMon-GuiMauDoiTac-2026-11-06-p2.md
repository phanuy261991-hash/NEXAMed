## 6. Bẫy và bài học phiên này
1. **API dev cache quyền**: sau `db:seed` quyền mới, API đang chạy vẫn trả 403 cho tới khi khởi động lại (nest watch tự khởi động lại khi sửa tệp). Kiểm bằng `curl` đăng nhập `dev.admin` + gọi route mới trước khi chạy Chrome.
2. **Typecheck của `apps/api` quét cả spec**: lỗi kiểu trong spec mới (kiểu quá hẹp cho `createMany`) làm `nest start --watch` báo "Found 2 errors" mà vẫn chạy — luôn `npx tsc --noEmit` ở `apps/api` sau khi viết spec.
3. **Đột biến sống sót = dữ liệu thử chưa phân biệt**: bỏ lọc "kết quả hiện hành" không đổi kết quả vì kết quả cũ có `signed_at` sớm hơn; đổi dữ liệu thử (bản đính chính ký MUỘN hơn) mới bắt được — và ép nghĩ lại ngữ nghĩa (thời gian trả = lần duyệt đầu tiên).
4. **Heredoc Bash với dấu nháy hay lỗi** (`unexpected EOF`): ghi script bằng công cụ Write rồi chạy `python <tệp>`; `node` trên Windows không đọc đường dẫn `/tmp/...` của Git Bash → dùng `cygpath -m`.
5. **Artifact publish báo "blocked by a Read permission rule"** khi dùng đường dẫn rút gọn `ADMINI~1` → dùng đường dẫn đầy đủ `C:\Users\Administrator\AppData\Local\Temp\claude\...`.
6. Ảnh dán trong chat KHÔNG tự thành tệp (chỉ ảnh đầu tiên có ở thư mục `images/`) — cần chủ dự án đặt tệp vào thư mục dự án nếu muốn dùng làm tài nguyên (logo có khẩu hiệu).
7. **Lỗi "khung bị bóp, nội dung bị cắt"**: khung `overflow-hidden` là con của cột flex có chiều cao cố định phải có `flex-shrink-0` (hoặc tự cuộn bên trong) — đã sửa Trung tâm báo cáo; công cụ quét `scripts/ui-audit/clipped-content-audit.cjs` (61 route × 2 cỡ, hiện 0 nghi vấn; chưa phủ route có tham số).
